# Evaluación Práctica: Unidad Didáctica 1
**Asignatura:** Entornos de Desarrollo  
**Curso:** 2025 - 2026  

---

## 📄 Descripción de la Tarea

Esta tarea de evaluación práctica está diseñada para verificar el dominio de los conceptos fundamentales abordados en la **Unidad Didáctica 1: Desarrollo de Software y Entornos de Desarrollo**.

El alumnado deberá demostrar la correcta instalación, configuración y uso inicial de un Entorno de Desarrollo Integrado (IDE), así como la aplicación de herramientas básico-operativas para el control de versiones y generación de documentación técnica.

---

## 🎯 Objetivos de Aprendizaje

- Identificar y diferenciar las etapas del ciclo de vida del software.
- Configurar un Entorno de Desarrollo Integrado (IDE) y sus herramientas complementarias.
- Crear, compilar y ejecutar un proyecto básico respetando las estructuras estándar.
- Utilizar conceptos básicos de control de versiones con Git para el seguimiento del trabajo.
