# Entornos de Desarrollo — Unidad 1

## 📚 Asignatura

**Entornos de Desarrollo**

Este repositorio contiene los trabajos, actividades y apuntes realizados durante la **Unidad 1** de la asignatura.

## 📖 Unidad 1

En esta unidad se trabajan conceptos relacionados con los **entornos de desarrollo**, la programación y las diferentes formas de describir y desarrollar una tarea.

### Contenidos

- Conceptos básicos de los entornos de desarrollo.
- Herramientas utilizadas durante el desarrollo de software.
- Diferencias entre descripción imperativa y declarativa.
- Organización y gestión de proyectos.
- Introducción al control de versiones.
- Uso de repositorios para almacenar y gestionar archivos.

## 🎯 Objetivo

El objetivo de esta unidad es conocer los conceptos básicos relacionados con los entornos de desarrollo y aprender a utilizar herramientas que facilitan la creación, organización y gestión de proyectos de software.

## 🛠️ Herramientas

Durante esta unidad se utilizan herramientas como:

- Git
- GitHub
- Entornos de desarrollo (IDE)
- Sistemas de control de versiones
